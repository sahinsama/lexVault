## [0.1.0] - 2026-07-30

### Added

* Initial CLI application
* Interactive terminal input
* Groq AI integration
* Automatic word analysis
* Meaning generation
* Example sentence generation
* Usage notes generation
* CEFR level detection
* IPA pronunciation generation
* Automatic word type detection
* Notion database integration
* Source selection
* Language selection
* Automatic date insertion
* Modular project structure
* Git version control
* GitHub repository

### Changed

* Refactored project into separate modules (`input`, `ai`, `notion`, `addWord`)

### Fixed

* Notion property validation issues
* Multi-select property handling
* Select property handling
* Word input supports spaces
* API configuration and authentication issues
